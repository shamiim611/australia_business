READING THE DATA

A little context goes a long way.

Percentages describe the selected population. Finance outcomes and reasons can refer to businesses that sought finance. Check the source notes for each measure.

Technology measures have different bases. Technology indicators include social media presence for this year. Broadband connection types refer to businesses using broadband as their main Internet connection. Read each chart's population and source notes. Internet income is in billions of Australian dollars.

Responses can overlap. Innovation types, markets, barriers and several other measures are not exclusive. Their percentages should not be added together.

Keep uncertainty in view. † marks an estimate with a source caution. NP means not available for publication. A rounded zero is identified separately; an unannotated blank remains missing.

Reading the years. Industry categories, population definitions and measures can differ between the supplied years. Year navigation opens separate snapshots; it does not calculate changes between them. No state or territory breakdowns are supplied for 2012–13.

Very uncertain estimates. !! marks a source estimate with relative standard error above 50%, considered too unreliable for general use. These values remain available in the source table but are excluded from bars and rankings.

This is a historical snapshot using the industries and survey coverage in the original publication. Reported changes are comparisons with the previous year, not a time series. Differences shown are descriptive, not tests of statistical significance.
